# Capturas UML

Guardar aquí exportaciones legibles de los diagramas `.puml` o equivalentes de Astah. Las capturas de fuentes PlantUML usan el nombre base del archivo; si una fuente contiene varias páginas, se añaden sufijos numéricos.

Las fuentes `.puml` tienen exportaciones PNG con el mismo nombre base; `domain-sequences.puml` genera páginas con sufijos numéricos. Los PDF recibidos se conservan como referencia.
